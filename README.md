# AI-Mock-Interview-Analyzer

An AI-powered mock interview system that analyzes resumes, conducts technical interviews, evaluates candidate answers using Machine Learning and NLP, and generates detailed performance insights.

## Features

* 📄 Resume analysis and skill detection
* 🎯 Technical interview track selection
* 🎙️ Voice-based answer submission
* ⌨️ Text-based answer submission
* 🤖 Machine Learning-based answer evaluation
* 🧠 NLP-based relevance and concept analysis
* 📊 Performance scoring and visualization
* 📈 Question-wise evaluation report
* 📷 Camera-based interview monitoring

## Technologies Used

* Python
* Streamlit
* Machine Learning
* Natural Language Processing (NLP)
* Scikit-learn
* Pandas
* NumPy
* PyMuPDF
* SpeechRecognition
* Plotly
* Joblib

## Project Overview

The system analyzes a candidate's resume to identify their technical domain and relevant skills. It then conducts a customized mock technical interview, accepts answers through voice or text, evaluates the responses using NLP and a trained Machine Learning model, and presents an overall performance report.

## How It Works

1. Upload the candidate's resume.
2. Extract skills and identify the technical domain.
3. Select the interview track and number of questions.
4. Conduct the mock interview.
5. Submit answers through voice or text.
6. Convert voice responses into text.
7. Analyze the answer using NLP features.
8. Evaluate the answer using the trained ML model.
9. Generate the final performance report.
